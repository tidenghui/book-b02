# 封箱

> 每一件遗物都有主人，除了那个签收的人。

**题材**：悬疑 · 心理 · 都市奇谭　**作者**：灯下人　**12 章 · 39,056 字**

遗物收纳师陈默接到一单怪活：把一间密室原封不动打包寄给已故委托人自己。密室里每件东西都指向她三年前失踪的妹妹陈曦。她一边封箱一边追查，发现委托人身份层层伪造，而收件地址是个空号。她按遗愿寄出箱子，在邮局监控里看到签收人——笔迹是妹妹的。三年来，妹妹一直藏在委托人背后，用遗物当棋盘，把姐姐一步步引向真相。
